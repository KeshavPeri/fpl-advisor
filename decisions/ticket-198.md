## HIGH-IMPACT

- **How the fixture report was sourced.** No "backtest report 10" exists anywhere in this repo's history — `docs/reports/` holds only report 7, which predates ticket #183's five-gameweek section entirely. Adding a `pull_request` trigger would make a whole-season Supabase read fire on every PR — a real policy change this ticket didn't ask for, and out of scope ("no change to any other workflow file" / no scope line asking for a new trigger). The step is correctly wired and will fire the day a future ticket adds that trigger; today it is dormant, which is the honest state given the ticket's own note that a changed workflow can't be exercised from inside an overnight session.
