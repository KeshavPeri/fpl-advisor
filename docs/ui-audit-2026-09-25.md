# UI audit — 25 Sept 2026 (from Keshav's iPhone screenshots)

Input for run 4's polish tickets. Keshav's words: "a lot of AI tell-tale signs littered across the UI …
add a title and be intentional." Nav bar: see `ui-nav-spec-2026-09-25.md`.

## Global
- G1 No screen titles. Every screen opens straight into a card, so nothing anchors you. Add a real title per screen.
- G2 Two card styles (blue glass vs near-black) used with no meaning. Pick one, plus one emphasis variant.
- G3 Monospace used at random: prices, countdown, deadline, chip statuses ("Available", "Locked"),
  "MAE". Keep mono only for tabular figures that need it; statuses and dates go sans.
- G4 Boilerplate filler: "X — built on real Premier League match history." under every player on
  Reasoning. It says nothing. Replace with the gbm-v1 top reasons (#266) or remove.
- G5 Repeated information: the same sentence as heading and again as the first bullet;
  "coin-flip" stated 2–3 times per card.
- G6 Hedging prose inside cards ("This is a five-gameweek view — a wildcard or free hit's real value
  depends on fixtures the model cannot see", "The solver only sees five gameweeks ahead, so…"). At most
  one short caption, or an info tooltip.
- G7 Jargon on screen: "MAE", "non-appearances", "baseline-v1", "1 of 3 solutions".
- G8 When scrolled, the glass header blob sits under the status bar and looks like a glitch.
